GET STARTED

Set up your accounts

  1. 01

    Pin Switchboard to your toolbar

    Open your browser’s Extensions menu and pin Switchboard to the toolbar. Click the green switch icon to open it.

  2. 02

    Save your first account

    Open the website, then open Switchboard. Check the detected address, click Connect, and allow access if asked. Sign in normally, then choose Add account → Save my current login. Give it a name and click Save login.

  3. 03

    Add another account

    Save unfinished work. This website’s tabs will refresh automatically. Choose Add account → Start new login, sign in, then return to Switchboard and click Save login.

EVERYDAY USE

Back to the right account.

Save unfinished work, then choose Switch beside the account you want. Check the name shown on the website before using it. Click Save login again after signing in again and before quitting Chrome.

A few useful things to know

Rename accounts and add websites

Choose Manage account → Rename to change an account’s label. Use the website picker to move between sites, or Add website to connect another.

Export a saved login

Choose Manage account → Export cookies, then .json or .txt. Both contain your last saved cookies in JSON format. For the latest cookies, select the account and click Save login again before exporting. Keep exports private: they can grant account access.

Removing an account does not sign you out

Remove saved account deletes the login saved in Switchboard. Remove website deletes all its saved entries. Current website cookies remain. To sign out, log out on the website, then remove the saved account from Switchboard.

Returning after a restart?

If the selected login needs restoring, save unfinished work and choose Manage account → Restore saved login. If a switch is interrupted, use Recover interrupted switch.

About staying signed in

Websites can expire or revoke sessions. Chrome switches cookies; other login storage remains shared, so compatibility varies by website. Switchboard does not hide your identity or guarantee protection from bans.
